# Servant Leadership Mastery Path

A free, structured, module-wise servant leadership training program — entry level to master level, with real frameworks, self-reflection tools, and a hands-on project at the end of each level.

**Live site:** https://sigilipelli.github.io/servant-leadership-mastery-path/

## Contents

- **Level 1 · Entry** — core philosophy, self-awareness, listening, empathy, trust, delegation basics
- **Level 2 · Intermediate** — coaching, conflict resolution, psychological safety, team development
- **Level 3 · Advanced** — culture, influence without authority, systems thinking, high-performing teams
- **Level 4 · Master** — executive-level servant leadership, culture at scale, crisis, legacy

## Local development

```bash
python3 -m venv .venv
.venv/bin/pip install mkdocs-material
.venv/bin/python -m mkdocs serve
```

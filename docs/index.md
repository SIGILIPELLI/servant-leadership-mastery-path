# Servant Leadership Mastery Path

A structured, module-wise servant leadership training program that takes you
from the core philosophy of leading by serving others to designing an
org-wide leadership development program — with real frameworks, self-
reflection tools, worked examples, and a hands-on exercise in every module.

This track is **not** about code — it's about the mindset, habits, and
practical skills of servant leadership: listening, empathy, trust,
delegation, coaching, and culture-building, worked through real frameworks
and reflection exercises rather than snippets.

## How the program is organized

| Level | Focus | Modules |
|-------|-------|---------|
| [Level 1 · Entry](level-1/index.md) | Core philosophy, self-awareness, listening, empathy, trust, delegation basics | 9 topics + 1 project |
| [Level 2 · Intermediate](level-2/index.md) | Coaching, conflict resolution, psychological safety, team development | 9 topics + 1 project |
| [Level 3 · Advanced](level-3/index.md) | Culture, influence without authority, systems thinking, high-performing teams | 9 topics + 1 project |
| [Level 4 · Master](level-4/index.md) | Executive-level servant leadership, culture at scale, crisis, legacy | 9 topics + 1 capstone |

## How to use this site

- Work through each level in order — later modules build on earlier ones.
- Every topic page includes concrete frameworks and models (as tables and
  structured examples), a real-world worked example or short case study, and
  an **Exercise** — a practical self-reflection or applied activity you
  actually do, not just read.
- Each level ends with a project: a real reflection document or plan you
  produce, not a code deliverable.
- Use the search bar (top of the page) to jump straight to a topic.

Start here → [Level 1 · Entry](level-1/index.md)

## What you'll need

Nothing but a notebook (physical or digital) and a willingness to reflect
honestly — most exercises ask you to apply a framework to your own team,
manager relationship, or a real situation you're navigating, so the more
specific and honest your answers, the more useful the exercise becomes.

🎥 **Prefer video?** Watch the [Mastery Path video series](https://youtube.com/@sigilipelli) on YouTube — Shorts and full walkthroughs of these lessons.
